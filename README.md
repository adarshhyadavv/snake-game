Snake Game

A simple and interactive Snake Game built using HTML, CSS, and JavaScript.

This project was created to practice JavaScript concepts such as DOM manipulation, event handling, arrays, objects, timers, localStorage, and game logic.

Features

* Snake movement using arrow keys
* Random food generation
* Score tracking
* High score persistence using localStorage
* Game timer
* Wall collision detection
* Self-collision detection
* Snake growth when food is eaten
* Restart game functionality
* Start and Game Over modals
* Keyboard controls

Technologies Used

* HTML5 — Game structure
* CSS3 — Styling and game board layout
* JavaScript — Game logic and interactions
* LocalStorage — Saving the high score
